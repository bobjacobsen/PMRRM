This directory contains copies of PMRRM LCC node backups.

The files are named from the node name, not including any date information included.

Note there are several special cases:

These are nodes being developed for future Zion East hard panel use, and will replace the node contents with similar names:

    - config-ZionE_turnouts_HP_1st.txt	
    - config-ZionE_turnouts_HP_2nd.txt

These are nodes that are not in active use, but may have some of their EventIDs in active use. They came from the prior ZionEast hard panel.

    - config-ZionE_panel_TWR1_21-11-11_NOT_IN_USE_POSSIBLE_CONFLICT.txt
    - config-ZionE_panel_TWR3_21-11-11_NOT_IN_USE_POSSIBLE_CONFLICT.txt
    - config-ZionE_panel_TWR2_21-11-11_NOT_IN_USE_POSSIBLE_CONFLICT.txt

The `checkNodeBackups` script is being developed to assist with checking new backup files against previous content to check for changes (originating here or on the layout)
